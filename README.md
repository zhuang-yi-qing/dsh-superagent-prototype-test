## 江湖夜雨

残阳如血，落在断魂崖上。崖下是万丈深谷，谷底一条白水如练，日夜不息地响。

青衫客倚剑而立，袖口被山风吹得猎猎作响。他等的人终于来了——一顶斗笠，一柄朽刀，脚步声轻得几乎不像活人。

“十年了。”斗笠客摘下帽子，露出一道自眉骨直劈到下颌的旧疤，“你追了我整整十年。”

“我要的不是你的命。”青衫客缓缓拔剑，剑身映出漫天晚霞，“是那夜死在渡口的三十二个人。”

十年前的那个雨夜，客船刚靠岸，火便从舱底烧了起来。撑船的、挑担的、抱着孩子赶路的，一个也没能走上岸。青衫客那时还是个少年，躲在芦苇丛里，把每一张脸都记了十年。

斗笠客放声大笑，笑声惊起一片寒鸦：“江湖上谁手上没有血？你师父当年屠过半座城，你怎么不去问他？”

话音未落，剑光骤起。

两人在崖顶交换一合，衣袂翻飞，石屑迸溅。青衫客左肩挨了一刀，血顺着指尖滴在青石上；斗笠客的刀锋却被削去半寸，火星四散。

“好剑。”斗笠客喘着气退开三步，“可你赢不了我，因为你心里还存着恨。”

青衫客沉默良久，忽然收剑入鞘。

“我不杀你。”他说，“我要你活着走到渡口，在那三十二座坟前，一一道歉，磕三个头。”

斗笠客怔立当场，继而伏地痛哭，像一头被生生剥了皮的困兽。

山雨落下来的时候，青衫客已经走远。崖上只余一柄断刀，和半壶将凉的残酒。

后来有人说，那夜之后，江湖上再没人见过他。渡口的石碑上被谁添了一行小字：恩怨到此为止。雨水年年冲刷，字迹却奇怪地清晰。
